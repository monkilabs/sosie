# @sosie/postgres

The Postgres source of [Sosie](https://github.com/monkilabs/sosie): a local
Postgres endpoint in front of a real database, read-only, that fakes every
value through [`@sosie/core`](https://www.npmjs.com/package/@sosie/core).

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
