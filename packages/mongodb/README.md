# @sosie/mongodb

The MongoDB source of [Sosie](https://github.com/monkilabs/sosie): a local
MongoDB endpoint in front of your database, read-only, that fakes every value
through [`@sosie/core`](https://www.npmjs.com/package/@sosie/core). mongosh,
the drivers and your app connect to it unchanged.

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
