# @sosie/mysql

The MySQL source of [Sosie](https://github.com/monkilabs/sosie): a local MySQL
endpoint in front of your database, read-only, that fakes every value through
[`@sosie/core`](https://www.npmjs.com/package/@sosie/core). The `mysql` client,
your app and its tests connect to it unchanged.

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
