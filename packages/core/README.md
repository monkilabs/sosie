# @sosie/core

The core of [Sosie](https://github.com/monkilabs/sosie): the source interface,
the neutral schema, `sosie.yml` rules, fakes by type, the mapping store,
`scan` and the MCP server. It knows no database or API; sources such as
[`@sosie/postgres`](https://www.npmjs.com/package/@sosie/postgres) build on it.

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
