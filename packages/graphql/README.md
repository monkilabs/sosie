# @sosie/graphql

The GraphQL source of [Sosie](https://github.com/monkilabs/sosie): a local
GraphQL endpoint in front of your team's own API, queries only, that fakes
every value through [`@sosie/core`](https://www.npmjs.com/package/@sosie/core).
It names each value from the schema and answers introspection itself.

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
