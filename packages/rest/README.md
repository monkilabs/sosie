# @sosie/rest

The REST source of [Sosie](https://github.com/monkilabs/sosie): a local HTTP
endpoint in front of your team's own API, `GET` and `HEAD` only, that fakes
every value through [`@sosie/core`](https://www.npmjs.com/package/@sosie/core).
It names each value from the API's OpenAPI document, or by where it sits.

Most people want [`@sosie/cli`](https://www.npmjs.com/package/@sosie/cli).
